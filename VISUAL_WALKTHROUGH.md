## স্ক্রিন ५: প্রোডাক্ট যোগ করা (Step-by-Step)

### ধাপ ১: "+ Add Product" ক্লিক করুন
```
┌────────────────────────────────────────────────────────────┐
│ [🔍 Search...] [➕ Add Product] ← এখানে ক্লিক করুন      │
└────────────────────────────────────────────────────────────┘
```

### ধাপ २: ফর্ম আসবে
```
┌────────────────────────────────────────────────────────────┐
│ ➕ Add New Product                                         │
│                                                             │
│ Product Name: [নাম লিখুন - যেমন "Smart Watch"]            │
│ Price (৳):    [দাম - যেমন "25000"]                       │
│ Category:     [ড্রপডাউন থেকে নির্বাচন করুন]             │
│ Image Style:  [স্টাইল নির্বাচন করুন]                     │
│ Rating:       [যেমন "4.5"]                               │
│ Review Count: [যেমন "150"]                               │
│                                                             │
│ Product Image (Optional):                                  │
│ [Choose file...] [Upload]                                 │
│                                                             │
│ [✅ Add Product] [❌ Cancel]                               │
└────────────────────────────────────────────────────────────┘
```

### ধাপ ३: ছবি আপলোড করুন (নতুন!)
```
"Upload" বাটন ক্লিক করুন → ফাইল নির্বাচন করুন → 
প্রিভিউ দেখুন → সেভ করুন
```

### ধাপ ४: ফর্ম সাবমিট করুন
```
[✅ Add Product] ← সবকিছু পূরণ করার পরে ক্লিক করুন
↓
নোটিফিকেশন: "Product added successfully!"
↓
নতুন প্রোডাক্ট টেবিলে আসবে
↓
মূল স্টোরে লাইভ হবে!
```

## স্ক্রিন ६: প্রোডাক্ট এডিট করা

### ধাপ ১: টেবিলে Edit খুঁজুন
```
┌─────────────────────────────────────────────────────────┐
│ #1│ Premium Sunglasses │ Accessories │ 15,479 │ [✏️] 🗑️ │
│                                               ↑
│                               এখানে Edit আইকন ক্লিক করুন
└─────────────────────────────────────────────────────────┘
```

### ধাপ २: ফর্ম খুলবে (সব ডেটা পূর্ণ থাকবে)
```
┌────────────────────────────────────────────────────────────┐
│ ✏️ Edit Product                                            │
│                                                             │
│ Product Name: [Premium Sunglasses] ← এডিট করুন          │
│ Price (৳):    [15479] ← দাম পরিবর্তন করতে পারবেন!      │
│ Category:     [Accessories ▼]                             │
│ Image Style:  [gradient-sunset ▼]                         │
│ Rating:       [4.8]                                       │
│ Review Count: [245]                                       │
│                                                             │
│ Product Image:                                             │
│ [Choose file...] [Upload]                                 │
│ [Preview: 📷 (ছবি আছে তো প্রিভিউ দেখবেন)]             │
│                                                             │
│ [💾 Save Changes] [❌ Cancel]                              │
└────────────────────────────────────────────────────────────┘
```

### ধাপ ३: পরিবর্তন করুন এবং সেভ করুন
```
1. প্রয়োজনীয় ফিল্ড এডিট করুন
2. নতুন ছবি চাইলে আপলোড করুন
3. [💾 Save Changes] ক্লিক করুন
4. নোটিফিকেশন আসবে: "Product updated successfully!"
```

## 🎯 সাধারণ ওয়ার্কফ্লো

```
START
  ↓
[⚙️ Admin বাটন]
  ↓
[Username + Password দিন]
  ↓
[Login]
  ↓
  ├─→ [✅ প্রোডাক্ট যোগ করতে] → "+ Add Product"
  │   ├→ ফর্ম পূরণ
  │   ├→ ছবি আপলোড
  │   └→ Save
  │
  ├─→ [✏️ প্রোডাক্ট এডিট করতে] → ✏️ আইকন
  │   ├→ তথ্য পরিবর্তন
  │   ├→ দাম বদলান
  │   ├→ ছবি চেঞ্জ করুন
  │   └→ Save Changes
  │
  └─→ [🗑️ প্রোডাক্ট মুছতে] → 🗑️ আইকন
      └→ কনফার্ম করুন
  ↓
[Logout বাটন]
  ↓
END
```
