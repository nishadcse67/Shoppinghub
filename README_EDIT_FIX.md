## 📞 সমস্যা হলে

### যদি ফর্ম খুলছে না:
```
1. পেজ রিফ্রেশ করুন (F5)
2. আবার Edit বাটন ক্লিক করুন
3. এখন খুলবে
```

### যদি Save হচ্ছে না:
```
1. সব ফিল্ড পূর্ণ আছে কি চেক করুন
2. দাম ০ এর চেয়ে বড় কি চেক করুন
3. নাম খালি নয় কি চেক করুন
4. আবার Save করুন
```

### যদি ছবি দেখা যাচ্ছে না:
```
1. ছবি ফরম্যাট JPG/PNG হওয়া উচিত
2. ছবি সাইজ ছোট হওয়া উচিত (< 5MB)
3. আবার আপলোড করুন
```
